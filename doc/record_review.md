# 复看历史曲线（record review）

本文说明记录页怎么找会话、载入要等多久、框选缩放与悬停读数怎么用，以及磁盘怎么自行清理。落盘数据的列语义与会话切分规则见 `doc/record_data.md`。

复看是只读的：整条链路上没有任何删除、轮转或截断记录的入口。

## 界面结构

主窗口新增「记录」页，左右两栏：

```
[使能开关 / 当前会话状态 / 记录目录 / 失败原因]
┌── 历史会话 ────────┐ ┌── 复看 ─────────────────┐
│ 开始时刻 端口      │ │ 读数：时刻 · 电压 · 电流 │  还原
│ 条数 · 状态 · 体积 │ │ 电压曲线（时间轴）       │
│ …                  │ │ 电流曲线（时间轴）       │
│ 3 个文件，共 21 MB │ └──────────────────────────┘
│ [重新扫描]         │
└────────────────────┘
```

开关拨到"记录"一侧即请求使能；正在记录时上方状态显示文件名与已写入条数。写盘失败会把原因显示在这里（例如目录不可写），但采样、控制与实时曲线照旧——记录坏了不影响用电。

## 找会话与载入

列表按开始时刻倒序，最新会话在最上面。每行两行信息：`开始时刻 端口` 与 `条数 · 状态 · 体积`，状态取"正常结束 / 中断 / 记录中"。

- 数据文件已不在记录目录的条目标为**文件缺失**并置灰：它仍在列表里，因为清单是这段数据存在过的唯一凭据；只是选不动。
- 「重新扫描」按钮重读 `index.json` 与目录体积。正在记录的那次会话也会出现在列表里，可以直接选来复看，画的是已经落盘的部分。
- 选中即整读该文件，进度条按每 2 万行一次刷新。实测开发机（无独显、机械盘外的常规 SATA SSD）：24 小时量级、8.9 MB、17.28 万行，从选中到画完 **0.23 秒**，规格预算 2 秒。载入期间界面不卡：解析分块进行，块间让出事件循环。
- 载入完成后读数行显示总条数、跳过行数（若有）与首末时刻。

## 框选缩放与还原

在任一张曲线上按住左键横向拖出一个框，松手即放大到这段时间：

- 两张曲线共用时间轴，一处框选，两处同时收敛；纵轴各自独立缩放。
- 放大是**从内存里的原始样本重新抽稀**，不是把折线拉伸：实测框选 10 分钟窗口得到 1201 个点，正好等于该窗口内的样本数，也就是回到了原始点密度。
- 还原有两种：双击曲线，或点读数行右侧的「还原」。还原后横轴回到会话的首末记录时刻。
- 框选宽度小于 6 个像素视为误点击，不放大。
- 框进了缺口里会明说"… 内没有记录（可还原）"，不会留一张空白图。

缺口按 `相邻 ts_ms 差 > 2.5 × 标称周期` 断段，每段一条独立折线，段与段之间不连线——所以采集中断在图上是**空洞**，而不是被直线连起来的渐变。

每一次中断都画成独立一段，段数不设上限；读数行末尾报出"中断 N 次"。上千次抖动的会话会画出一千多条折线，载入仍按上面的实测时间走，但段数越万时绘制时间会逼近 2 秒上限——那种会话先框选放大到一段时间再看。

## 悬停读数

把光标移到曲线上的点上，读数行显示该记录的时刻（精确到毫秒）、电压与电流，与 CSV 中对应行一致；光标离开即不再刷新，读数保持上一次内容。

## 体积与自行清理

列表下方显示记录目录的文件数与总字节数（`storage_summary` 现算，不缓存）。应用不自动清理，也不提供删除按钮——要腾磁盘请自行操作：

1. 关闭记录开关并断开设备（或退出应用），避免删掉正在写的文件。
2. 直接删 `<记录目录>/<会话>.csv`。
3. 清单条目可以留着：文件不在时列表把它标成"文件缺失"，仍然看得见；要连条目一起清掉，编辑 `records/index.json` 删掉对应对象即可。清单内容不可用时整份当作"没有历史"，不会报错。
4. 点「重新扫描」让界面与磁盘一致。

想改存放位置：编辑 `config/record_settings.json` 的 `dir` 字段（相对路径按仓库根或 exe 同级解析），把整个 `records/` 目录搬过去后重启应用。
