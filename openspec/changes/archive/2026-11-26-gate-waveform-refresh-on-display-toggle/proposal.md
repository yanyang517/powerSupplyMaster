# Proposal

## Why

波形页的“显示波形”复选框目前只依赖 Qt 的视觉禁用效果，图表数据仍会随每轮采样持续积累和重绘。该开关因此没有真正控制波形刷新，既与用户预期不一致，也在隐藏波形时持续产生不必要的图表更新。

## What Changes

- 未勾选“显示波形”时，电压和电流图表保持禁用，并停止曲线数据累计、序列替换和坐标轴更新。
- 勾选“显示波形”后，从下一组有效电压/电流采样开始恢复曲线刷新。
- 暂停期间不补绘被跳过的采样；已有曲线保留，重新启用后从后续采样继续。
- 电压/电流读数、悬浮窗、设备周期采样、异常提示和数据记录不受该开关影响。
- 复用现有 `ui/live-curve` 能力补充波形显示开关的行为约束，不新增后端接口或设备协议。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `ui/live-curve`: 新增“显示波形”开关对图表禁用状态、刷新暂停与恢复的约束，并明确波形刷新不改变现有采样和记录链路。

## Impact

- 视图：修改 `src/views/main_window.py`，在图表更新入口读取“显示波形”的勾选状态；沿用 Qt 可勾选 `QGroupBox` 对图表子控件的禁用语义，不修改 `.ui` 文件。
- 测试：扩展 `src/views/test_live_curve_window.py`，覆盖默认禁用、暂停不累计、恢复更新及读数持续刷新；保持现有滚动窗口和采集中断测试通过。
- 采样与记录：`src/presenter/presenter.py` 的周期采样、成对数据读取和记录逻辑无需改变。
- 接口与依赖：不涉及 TCP/SCPI 协议、服务端路由、持久化格式或第三方依赖。
- 实施工作流：按项目约束，后续实施 MUST 在独立 git worktree 和修复分支中进行；合入 master 时 MUST 使用 `git merge --no-ff`。
