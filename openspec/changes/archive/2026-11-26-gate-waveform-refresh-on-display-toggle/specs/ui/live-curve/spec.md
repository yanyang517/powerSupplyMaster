# Spec Delta

## ADDED Requirements

### Requirement: 显示波形开关控制曲线刷新

波形页 SHALL 仅在用户勾选“显示波形”时更新电压和电流实时曲线。未勾选时，图表 MUST 处于禁用状态，且 MUST NOT 累计新数据点、替换曲线序列或改变曲线坐标轴。

#### Scenario: 默认未勾选时图表禁用

- **WHEN** 应用启动并进入波形页
- **THEN** “显示波形”默认未勾选
- **AND** 电压和电流图表均处于禁用状态

#### Scenario: 未勾选时忽略新采样

- **WHEN** “显示波形”未勾选且设备持续产生有效采样
- **THEN** 两条曲线的数据点、序列内容和坐标轴范围保持不变
- **AND** 电压和电流读数仍随有效采样更新

#### Scenario: 重新勾选后恢复后续采样

- **WHEN** 用户重新勾选“显示波形”
- **THEN** 电压和电流图表恢复可用
- **AND** 从下一组有效采样开始追加曲线
- **AND** 暂停期间被跳过的采样 MUST NOT 补绘到曲线中

### Requirement: 波形刷新不改变采样与记录

“显示波形”开关的作用范围 SHALL 仅限于实时曲线。该开关 MUST NOT 停止设备周期采样，或改变电压/电流读数、悬浮窗、采集中断提示和数据记录的行为。

#### Scenario: 暂停曲线时记录仍继续

- **WHEN** “显示波形”未勾选且数据记录已使能
- **THEN** 每个有效采样周期仍只读取一次电压和一次电流
- **AND** 该组成对数据仍写入记录
- **AND** 每个成功周期对设备的读取次数与勾选波形时相同

#### Scenario: 暂停曲线时异常提示仍有效

- **WHEN** “显示波形”未勾选且设备连续采集失败
- **THEN** 采样循环继续按周期尝试
- **AND** 界面仍按既有阈值显示采集中断状态
